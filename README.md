# Task Manager

A simple task management web application built using HTML, CSS, and JavaScript. It allows users to add, complete, and delete tasks through a clean interface.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Toggle task completion status

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
task-manager/
│
├── index.html
├── style.css
├── script.js
├── README.md
└── .gitignore
```

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/jhakumarrahul4/task-manager
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
